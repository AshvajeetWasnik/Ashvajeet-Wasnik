## 2️⃣ Anti Money Laundering Transactions Analysis

🔗 [View Dashboard](#) &nbsp;|&nbsp; **Tools:** `Python` `SQL` `Tableau`

- **Overview:** Built a dashboard analyzing **5.08M transactions (30.41T)** to isolate **5,177 laundering cases (0.10%)** worth **187.07B**.
- **Insights:**
  - Detected layering networks across **14,000+ receivers**, flagging the top suspicious accounts (**243** and **158 cases**) and a peak daily volume of **539 cases**.
  - Pinpointed the primary channels: **86% (4,483 cases) via ACH** and **63% in USD/EUR**, to guide audit holds and transfer caps.
- **Impact:** Delivered actionable recommendations to address the issue.
